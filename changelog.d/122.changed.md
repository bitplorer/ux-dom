- **One contract for HTML boolean attributes (#122).** For the spec's boolean attributes
  (``checked``, ``disabled``, ``selected``, ``required``, ``readonly``, ``multiple``,
  ``open``, ``autofocus``, ``novalidate``, ``formnovalidate``, … : ``BOOLEAN_ATTRIBUTES``),
  ``True`` renders ``name="name"``, ``False`` and ``None`` omit the attribute, and any
  other value raises ``TypeError``. Before, ``checked="unchecked"`` and ``checked=None``
  rendered a checked box, and ``tag["disabled"] = True`` rendered ``disabled="True"``.
  Parsed HTML keeps a boolean attribute as ``True``. ``hidden`` (enumerated), htmx /
  Alpine attributes and SVG tags are not governed. ``BooleanInput``, ``CheckboxInput``,
  ``RadioInput`` and ``BooleanField`` take ``checked: bool | None``; the
  ``"checked"`` / ``"unchecked"`` / ``"null"`` strings are gone, and ``BooleanInput`` /
  ``RadioInput`` now default to unchecked (ux-valio reads ``None`` as "use the
  default", so a checked default made ``checked=None`` render checked).
