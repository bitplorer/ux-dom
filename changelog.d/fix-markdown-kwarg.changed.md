- **Component `markdown=` contract** is decided by `render`'s signature, not by the value's type. If `render` does not declare `markdown`, the value is the Markdown converter: a callable or an object with `.convert` is used, `None` keeps the default (marko). Any other value now raises `TypeError` ("`<Class>(markdown=...)` expects a Markdown converter …") instead of being silently ignored. This also applies to `MarkdownElement`.
