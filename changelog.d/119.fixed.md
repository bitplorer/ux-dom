- **XElement applies a WebSocket message to the DOM (#119).** A message
  ``{id, attr, newVal}`` for the element now sets that attribute; before, it only set a
  JS property and the attribute kept its old value. Only a declared attribute that is
  not URL-bearing (the Python ``URL_ATTRIBUTES``, ``SAME_ORIGIN_URL_ATTRIBUTES`` and
  srcset names, embedded in ``x_element.js`` with a drift-guard test), ``srcdoc``,
  ``style`` or an ``on*`` handler can change, because the #107 URL policy runs only in
  Python. Any other message is refused with a ``console.warn`` and the socket stays
  open. The offline Chromium harness asserts both. ``docs/reference/API_SURFACE.md``
  states the tag-name collision rule: a trailing ``_`` for builtins, ``time_`` as the
  one exception.
