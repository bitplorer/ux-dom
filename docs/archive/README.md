# Archive

Historical audits, migration notes, and one-off investigation dumps live here.

**Rules:**

- Not product docs — current contracts live under `docs/guides/`,
  `docs/internals/`, `docs/security/`, and `docs/ship/`.
- Never the only source of truth for a shipping API.
- Prefer summarizing durable lessons into
  [MAINTENANCE_CANON.md](../ship/MAINTENANCE_CANON.md) or
  [STABILITY.md](../ship/STABILITY.md) instead of growing archive-only canons.

As of **0.1.0**, residual risk and hardened edges are tracked in
[STABILITY.md](../ship/STABILITY.md) (there is no separate live `BUGS_AUDIT.md`).
